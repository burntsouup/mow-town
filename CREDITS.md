## Assets

None yet. Everything is placeholder geometry, textures drawn in code, and sounds synthesized
in code (see `docs/DECISIONS.md` #13).

When adding an asset, prefer CC0 and add a line here:

```
- <what it is> — <author>, <source URL>, <license>
```

Good CC0 sources: [ambientCG](https://ambientcg.com/) and [Poly Haven](https://polyhaven.com/)
(textures, skies), [Kenney](https://kenney.nl/) (models, audio),
[Freesound](https://freesound.org/) (filter by the CC0 license).
